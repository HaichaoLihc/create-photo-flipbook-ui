# Hawaii v1 evaluation

Use this case to measure whether the skill can turn a photo-book reference and
supplied imagery into a correct, extensible interactive website.

Keep the raw task inputs in an isolated temporary workspace. Do not expose
`examples/hawaii-book/`, this rubric, prior diagnoses, or expected screenshots
to the agent performing the task.

Evaluate the produced site only after its production build succeeds. Compare
the result with the ground-truth implementation using the rubric in
`rubric.json`. Record pass/fail evidence, elapsed time, generation count, and
any manual intervention.

The ground-truth project is not itself a task input. Add licensed or
user-approved raw input fixtures before running this as a reproducible eval.
