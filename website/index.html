How it works

  1. Select your photos

    Provide images, a local folder, or finished pages. Work with Codex to choose the photos and arrange a sequence.

  2. Design the book

    Describe the style you want. Keep the original photos, or use a companion photo skill to create an editorial treatment.

  3. Build and publish

    Generate a responsive photo flipbook with the bundled 2D reader. Preview it locally, edit the files, and publish it when ready.

Get started

Install the skill in Codex, add your photographs, and try this prompt:

Use $create-photo-flipbook-ui to turn these photographs into a photobook. Find a thoughtful sequence, keep the original photos, and build a website I can flip through.

Works with travel journals, family albums, photo essays, and portfolios.

Questions

Can I upload photos here?
This site is an introduction and demo. To create your own photo flipbook, use the skill in Codex with your photographs or a local folder.
What’s included?
A 2D page-turning reader, photo sequencing guidance, and tools for contact sheets and photo-library workflows. The repository also has optional 3D readers, a bookshelf, and galleries. The demo above uses the 3D Book 2 template.
Can I customize and publish my book?
Yes. You get website files you can edit and host yourself. Change the sequence, typography, colors, and layout, then publish on GitHub Pages or another static web host.
