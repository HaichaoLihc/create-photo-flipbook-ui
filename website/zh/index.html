制作流程

  1. 挑选照片

    提供照片、本地文件夹或已经设计好的页面。和 Codex 一起选出照片，安排它们在书中的顺序。

  2. 设计相册

    描述你喜欢的风格。可以保留原始照片，也可以搭配其他照片技能，做出更有表现力的画面与排版。

  3. 生成并发布

    使用自带的 2D 阅读器生成适配不同屏幕的翻页相册。先在本地预览、修改文件，满意后再发布。

开始制作

在 Codex 中安装技能，添加照片，然后试试这样描述：

使用 $create-photo-flipbook-ui，把这些照片制作成一本相册。安排有叙事感的照片顺序，保留原始照片，并生成一个可以翻页浏览的网站。

适合旅行记录、家庭相册、摄影故事和作品集。

常见问题

可以直接在这里上传照片吗？
这里是项目介绍和演示网站。制作自己的翻页相册时，请在 Codex 中使用这项技能，并提供照片或本地文件夹。
项目包含什么？
包含 2D 翻页阅读器、照片编排指导，以及用于照片总览图和照片库工作流的工具。仓库还提供可选的 3D 阅读器、书架和画廊模板。上方演示使用的是 3D Book 2 模板。
可以修改和发布自己的相册吗？
可以。你会得到可自行编辑和托管的网站文件。调整照片顺序、字体、配色和排版后，即可发布到 GitHub Pages 或其他静态网站托管平台。
项目是开源的吗？
项目原创代码和技能采用 MIT 许可证，第三方组件保留各自的许可证。除非另有明确说明，改编的 3D Book 1 代码和所有媒体内容不在此授权范围内。查看许可证说明。
